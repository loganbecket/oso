name: oso-doctor
description: Look after Oso itself. Use when the student says open my settings, open Oso, Oso status, is Oso OK, update Oso, sync now, back up now, or when the briefing is missing, deadlines look stale, or a connection shows as failing.
---

Call the `skill_instructions` tool with name `oso-doctor` and follow the instructions it returns. If that tool is unavailable, read `Oso/Skills/oso-doctor.md` in the vault (through Google Drive if needed) and follow it, along with any notes in `Oso/Rules/` about this command or everything. If neither is reachable, Oso itself is not running on his computer: tell him to run `oso doctor --fix` in a command window (PowerShell on Windows, Terminal on a Mac) and follow what it says.
