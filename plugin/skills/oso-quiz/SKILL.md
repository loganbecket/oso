# Quiz

1. Find the notes for the topic or exam the student named (`list_notes` on the course folder, or a search for the topic; for an exam, its date from `list_deadlines`) and read them.
2. Ask in the chat as many questions as the student wants; with no number, five. Model them on the homework and examples in the notes, and only ask what the materials can answer. Do not show answers.
3. When the student answers, mark each right, partly right, or wrong; for anything not fully right, show the method briefly with a `[[path]]` citation. End with the score and the topic or two to review.

For a full-length practice exam (the student asks for a practice test or exam), delegate the writing to the `oso-examiner` agent with the scope and the notes you gathered. Save a file only if the student asks. No answers before an attempt unless they say they are done trying.
